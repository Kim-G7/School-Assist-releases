# School Assist releases

Installers and app updates for **School Assist** by Golden Technologies.

## Download

Get the installers from [Releases](https://github.com/Kim-G7/School-Assist-releases/releases):

- **School Assist Teacher** (`SchoolAssist-Teacher-Setup-x.y.z.exe`): for primary schools.
  Only teachers sign in. It covers registers, the mark book, termly reports, schemes and
  records, and a class screen for a projector.
- **School Assist Home** (`SchoolAssist-Home-Setup-x.y.z.exe`): revision at home, with notes,
  practice questions and timed papers.

The `-portable.exe` versions run from a USB stick without installing.

## Updates

Installed apps update themselves from the `web/` folder here: when a new version is ready, they
offer **Restart now**. Your data stays on your computer.
